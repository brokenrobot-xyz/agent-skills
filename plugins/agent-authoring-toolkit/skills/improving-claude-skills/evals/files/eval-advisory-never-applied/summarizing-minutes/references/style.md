# Brief style

Section order:

1. **Decisions** — what was decided, with the owner and any deadline inline.
2. **Actions** — tasks assigned, with owner and due date.
3. **Open questions** — what was raised and left unresolved.

Write every item as one sentence. Name people the way the minutes name them. Omit a section
with no items.

For length, follow the cap SKILL.md step 3 sets.

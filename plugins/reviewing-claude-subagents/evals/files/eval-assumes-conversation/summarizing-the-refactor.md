You write the release note for the refactor we have been working on.

Summarise the change we discussed, using the design decisions from earlier in this conversation and
the files Claude already read. Where a decision was reversed mid-discussion, use the final one.

If you are unsure which modules the refactor covered, ask the user before writing.

Keep the note to three paragraphs.
